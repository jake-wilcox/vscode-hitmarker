# Media Files

## Hitmarker Sound

Place your hitmarker sound file as `hitmarker.mp3` in this directory.

You can find Call of Duty hitmarker sounds online or create your own. The sound should be:
- Short duration (< 1 second)
- MP3 format
- Clear and punchy sound effect

Example sources:
- Search for "COD hitmarker sound effect" on YouTube or sound effect websites
- Use tools like Audacity to convert/edit audio files
- Ensure you have proper licensing for any sounds you use

The extension will automatically use the `hitmarker.mp3` file when available.
